## Non-blocking harness findings

### H-01 — startup wait deviated from event-driven ideal

The supervisor used one short `sleep 6` while checking that the freshly spawned T8 worker had connected before prompt delivery. Current Harness Contract and Spawn Recipe already prohibit fixed sleeps/polling as the normal lifecycle clock. This run therefore does **not** normalize that behavior. It is a bounded ergonomics debt for later hardening, not a qualification blocker.

### H-02 — reviewer admission was not error-free

T8 required one bounded reoffered reviewer run after an admission refusal. The current provider-owned retry path recovered safely. This proves resilience, not perfection; reviewer-result admission reliability remains observable debt.

### H-03 — no new controller is justified

Neither finding requires a new runner, polling daemon, state machine or second review controller. Existing authority ownership and fail-closed behavior were sufficient.
