# Atenea — Agent instructions

Atenea is an isolated workflow laboratory for testing whether the full Matt Pocock engineering-skills ecosystem can coexist cleanly with the full Gentle AI ecosystem inside OpenCode.

See `README.md` for the experiment's objective, working principles, and qualification sequence.

## Agent skills

### Issue tracker

Issues live as GitHub issues in this repo, managed via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

The five canonical triage roles use the default label strings. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context layout: one `CONTEXT.md` plus `docs/adr/` at the repo root. See `docs/agents/domain.md`.
