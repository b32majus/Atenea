# Historical Atenea Runtime Artifacts

Status: **HISTORICAL / NON-OPERATIVE**

This directory preserves implementation artifacts from pre-vNext Atenea runtime epochs.

They are retained for provenance, regression archaeology, and explanation of prior decisions. They are **not** part of the current execution path and must not be imported, installed, sourced, patched, or treated as current authority.

Current execution authority lives in the promoted/vNext policy surfaces and native Pi/Gentle runtime.

Examples archived here include:

- Atenea RDD consent relay;
- pi-intercom unattended checks;
- historical Gentle host/ASSESS bridge patches;
- historical effective-mode fixture;
- superseded runtime/profile authority checks.

The existence of these files does not imply they should be reactivated.

If a future upstream regression appears, reproduce it against the current supported native stack first. Historical code may be consulted as evidence, but it must not be restored as production machinery without a new explicit architectural decision and qualification.
